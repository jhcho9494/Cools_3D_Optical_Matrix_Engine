# Public Disclosure, Intellectual Property, and Collaboration Notice

## 1. Purpose of this repository

This repository presents a public architectural overview of the Cools 3D Optical Matrix Engine.

The disclosed concept includes, at a high level:

- a two-dimensional individually addressable light-source plane,
- a transparent optical host containing a three-dimensional distribution of refractive-index weight features,
- one-pass optical linear transformation through the weight volume,
- a two-dimensional detector plane,
- differential detection for signed matrix outputs,
- interferometric detection for complex matrix outputs,
- local rewriting of selected nonvolatile weight features,
- thermal stabilization of the source array and optical host,
- thermal isolation and thermal-null optical coupling,
- and representative semiconductor-light-source integration structures.

This repository is intended for technical communication, public architectural disclosure, collaboration discussion, and identification of the associated Cools technology platform.
